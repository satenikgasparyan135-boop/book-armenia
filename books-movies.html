🎬 50 Լավագույն գրքեր և ֆիլմեր

1. Խորհրդավոր կղզին (Ժյուլ Վեռն) Արկածային / Ֆիլմ և Գիրք

Արկածային վեպ օդապարով չբնակեցված կղզի ընկած մարդկանց մասին, ովքեր ստեղծում են քաղաքակրթություն:

2. Կոմս Մոնտե Քրիստո (Ալեքսանդր Դյումա) Դրամա / Էկրանավորում

Համաշխարհային գլուխգործոց վրեժխնդրության, արդարության և անսահման սիրո մասին:

3. Փարիզի Աստվածամոր Տաճարը (Վիկտոր Հյուգո) Պատմավեպ / Ֆիլմ

Խորապես հուզող պատմություն միջնադարյան Փարիզի, Եսմերախի և Կվազիմոդոյի մասին:

4. Ոճիր և պատիժ (Ֆեոդոր Դոստոևսկի) Հոգեբանական / Ֆիլմ

Հոգեբանական խորը վերլուծություն մարդկային խղճի, բարոյականության և ներքին պայքարի մասին:

5. Հարի Փոթերը և փիլիսոփայական քարը (Ջոան Ռոուլինգ) Ֆենթզի / Ֆիլմաշար

Կախարդանքի, հավատարիմ ընկերության և բարու ու չարի հավերժական պայքարի հրաշալի աշխարհ:

6. Փոքրիկ իշխանը (Անտուան դը Սենթ-Էքյուպերի) Անիմացիա / Գիրք

Փիլիսոփայական հեքիաթ սիրո, ընկերության, պատասխանատվության և մարդկային սրտի պարզության մասին:

7. Տանջանք և խրախճանք (Վիլյամ Սարոյան) Գեղարվեստական արձակ

Ջերմ ու մարդկային պատմություններ կյանքի, հույսի և հայկական հոգեբանության մասին:

8. Մատանիների տիրակալը (Ջ. Ռ. Ռ. Թոլքին) Բարձր Ֆենթզի / Կինոգլուխգործոց

Ֆենթզի ժանրի վեհագույն էպոպեա՝ Միջերկրում Մատանին ոչնչացնելու վտանգավոր ճանապարհորդության մասին:

9. Հարյուր տարվա մենություն (Գաբրիել Գարսիա Մարկես) Մոգական ռեալիզմ

Մոգական ռեալիզմի գլուխգործոց Բուենդիա ընտանիքի և Մակոնդո քաղաքի պատմության մասին:

10. 1984 (Ջորջ Օրուել) Հակաուտոպիա / Ֆիլմ

Տագնապալի հակաուտոպիական վեպ տոտալիտար համակարգերի և ազատության պայքարի մասին:

11. Սամվել (Րաֆֆի) Պատմավեպ

Պատմավեպ Հայաստանի ծանր ու ճակատագրական ժամանակաշրջանի և հայրենասիրության մասին:

12. Վերք Հայաստանի (Խաչատուր Աբովյան) Վեպ / Պատմական

Հայ նոր գրականության հիմնաքարը, որը պատմում է հայ ժողովրդի հերոսական պայքարի մասին:

13. Աննա Կարենինա (Լև Տոլստոյ) Սոցիալական դրամա / Ֆիլմ

Խորը հոգեբանական դրամա սիրո, ընտանեկան արժեքների և հասարակական նորմերի բախման մասին:

14. Պատերազմ և խաղաղություն (Լև Տոլստոյ) Էպիկական վեպ / Ֆիլմ

Համաշխարհային գրականության վեհագույն վեպը 1812 թվականի պատերազմի և մարդկային ճակատագրերի մասին:

15. Մեծն Գեթսբի (Ֆրենսիս Սքոթ Ֆիցջերալդ) Դասական վեպ / Հոլիվուդյան ֆիլմ

«Ջազի դարաշրջանի» տպավորիչ պատմություն ամերիկյան երազանքի և անպատասխան սիրո մասին:

16. Համլետ (Ուիլյամ Շեքսպիր) Ողբերգություն / Կինոթատրոն

«Լինել, թե չլինել»․ համաշխարհային դրամատուրգիայի փիլիսոփայական գլուխգործոցը:

17. Ռոմեո և Ջուլիետ (Ուիլյամ Շեքսպիր) Ռոմանտիկ ողբերգություն

Անմահ ողբերգություն երկու երիտասարդների մաքուր սիրո և թշնամի ընտանիքների մասին:

18. Տասնհինգամյա նավապետը (Ժյուլ Վեռն) Արկածային / Ֆիլմ

Հետաքրքրաշարժ արկածներ օվկիանոսում և Աֆրիկայի ջունգլիներում պատանի Դիկ Սենդի մասնակցությամբ:

19. Կապիտան Գրանտի որդիները (Ժյուլ Վեռն) Արկածային / Ֆիլմ

Համաշխարհային օվկիանոսով և անհայտ երկրներով անցնող անմոռանալի որոնումներ:

20. Շուրջերկրյա ճանապարհորդություն 80 օրում (Ժյուլ Վեռն) Արկածային / Ֆիլմ

Ֆիլաս Ֆոգի զարմանահրաշ և արկածներով լի ճամփորդությունը ամբողջ աշխարհով շուրջ:

21. Երեք հրացանակիրները (Ալեքսանդր Դյումա) Պատմաարկածային / Ֆիլմ

Ընկերության, սիրո և քաջության խորհրդանիշ դարձած արկածային վեպ դարաշրջանի մասին:

22. Քսան տարի անց (Ալեքսանդր Դյումա) Պատմաարկածային

Սիրված հրացանակիրների վերադարձը և նոր վտանգավոր փորձությունները տարիներ անց:

23. Սպիտակ ժանիք (Ջեք Լոնդոն) Արկածային / Ֆիլմ

Հյուսիսային վայրի բնության մեջ գոյատևող գայլշների և մարդու բարության մասին հուզիչ պատմություն:

24. Մարտին Իդեն (Ջեք Լոնդոն) Վեպ / Ֆիլմ

Նպատակասլաց երիտասարդի դժվարին ուղին դեպի գրական հաջողություն և ճանաչում:

25. Խաչագողի հիշատակարանը (Րաֆֆի) Սոցիալական վեպ

Խորը հասարակական վերլուծություն հայ իրականության բարոյական խնդիրների մասին:

26. Կայծեր (Րաֆֆի) Պատմաազգագրական

Հայ ազգային-ազատագրական պայքարի և լուսավորության գաղափարների հզոր ստեղծագործություն:

27. Գևորգ Մարզպետունի (Մուրացան) Պատմավեպ

Պատմավեպ հայոց պետականության վերականգնման և նվիրյալ հերոսների պայքարի մասին:

28. Անուշ (Հովհաննես Թումանյան) Պոեմ / Օպերա

Անմահ պոեմ գյուղական կյանքի, սիրո, ավանդույթների և ողբերգական ճակատագրի մասին:

29. Քաոս (Շիրվանզադե) Սոցիալական դրամա / Ֆիլմ

Ընտանեկան վարքագծի, բարոյականության անկման և կապիտալիզմի ազդեցության հոգեբանական պատկեր:

30. Վարդանանք (Դերենիկ Դեմիրճյան) Պատմավեպ

Ավարայրի ճակատամարտին և հայ ժողովրդի հայրենասիրական ոգուն նվիրված հոյակապ վեպ:

31. Դորիան Գրեյի նկարը (Օսկար Ուայլդ) Փիլիսոփայական / Ֆիլմ

Խորը և խորհրդանշական պատմություն գեղեցկության, հոգու անկման և արատների մասին:

32. Ֆրանկենշտեյն (Մերի Շելի) Գիտական ֆանտաստիկա / Սարսափ ֆիլմ

Գիտական էթիկայի և արարչության սահմանների մասին հիմնարար ստեղծագործություն:

33. Ոդիսական (Հոմերոս) Էպիկական պոեմ / Ֆիլմ

Հնագույն և անմահ էպոպեա Ոդիսևսի դժվարին տունդարձի և արկածների մասին:

34. Կանաչ մղոնը (Սթիվեն Քինգ) Դրամա / Լեգենդար ֆիլմ

Հուզիչ և խորհրդավոր պատմություն մահապատժի դատապարտվածների բանտում տեղ գտած հրաշքների մասին:

35. Ալքիմիկոսը (Պաուլո Կոելիո) Փիլիսոփայական առակ

Ոգեշնչող պատմություն սեփական երազանքին հետևելու և սեփական ճանապարհը գտնելու մասին:

36. Մեծապատիվ մուրացկաններ (Հակոբ Պարոնյան) Սատիրա / Ներկայացում

Սուր և անզուգական երգիծանք հասարակական արատների ու կեղծավորության մասին:

37. Բանաստեղծություններ (Վահան Տերյան) Քնարերգություն

Նուրբ, մելամաղձոտ և հայրենասեր սիրո անզուգական քնարերգություն:

38. Մատյան ողբերգության (Գրիգոր Նարեկացի) Հոգևոր պոեզիա

Համաշխարհային հոգևոր մտքի գլուխգործոց՝ մարդու և Աստծո խորը ներքին զրույցը:

39. Ալիսը Հրաշքների աշխարհում (Լյուիս Քերոլ) Ֆանտաստիկա / Կինոկադր

Զարմանահրաշ և անհավանական արկածներ տրամաբանության և երևակայության սահմաններից այն կողմ:

40. Մարդը, որ ծիծաղում է (Վիկտոր Հյուգո) Վեպ / Դրամա ֆիլմ

Խորապես հուզող պատմություն սիրո, արդարության և հասարակական անհավասարության մասին:

41. Մեր ժամանակների հերոսը (Միխայիլ Լերմոնտով) Հոգեբանական վեպ / Ֆիլմ

Ռուսական գրականության առաջին հոգեբանական վեպը մարդկային բնույթի բարդությունների մասին:

42. Ծովային գայլը (Ջեք Լոնդոն) Արկածային / Ֆիլմ

Կոշտ բնավորությունների, գոյատևման և փիլիսոփայական բախումների պատմություն օվկիանոսում:

43. Ապուշը (Ֆեոդոր Դոստոևսկի) Հոգեբանական վեպ / Էկրանավորում

Միշկին իշխանի բարության, անկեղծության և անողոք իրականության ողբերգական բախումը:

44. Անտառային մարդիկ (Մուրացան) Վեպ

Հայ գյուղական կյանքի, սովորույթների և հասարակ մարդկանց հոգեբանության վառ պատկեր:

45. Ժայռը (Բակունց) Արձակ / Ֆիլմ

Անզուգական հայկական բնաշխարհը և մարդկային հուզիչ ճակատագրեր Ակսել Բակունցի գրչով:

46. Աստղային տղան (Օսկար Ուայլդ) Հեքիաթ / Ֆիլմ-հեքիաթ

Խորապես բարոյախոսական հեքիաթ գեղեցկության, հպարտության և ներքին վերածննդի մասին:

47. Ծիրանի ծառ (Համո Սահյան) Բանաստեղծություններ

Հարազատ հողին, բնությանը և հայկական արմատներին նվիրված անկրկնելի քնարերգություն:

48. Հայրեր և որդիներ (Իվան Տուրգենև) Սոցիալական վեպ / Ֆիլմ

Սերունդների բախման և հասարակական հայացքների փոփոխության հիմնարար վեպ:

49. Առյուծը, կախարդը և զգեստապահարանը (Կ. Ս. Լյուիս) Ֆենթզի / Հոլիվուդյան ֆիլմ

Կախարդական Նարնիա աշխարհը, որտեղ բարին միշտ հաղթում է չարին:

50. Հացի բանվորը (Նար-Դոս) Վեպ / Դրամա

Նար-Դոսի հոգեբանական և սոցիալական դրաման մտավորականի և ստեղծագործողի ճակատագրի մասին:
